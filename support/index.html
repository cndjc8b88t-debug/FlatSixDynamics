Support

FlatSixDynamics is built by a small team of highly trained experts. There is no support desk, no ticketing system, no chat widget. There is one inbox, which is read.

If something is wrong — a crash, a wrong number on the cockpit overlay, a translation that reads strangely, a setting that won't stick — please write. We answer in English. We answer within a few days.

support@flatsixdynamics.com

Reporting a problem usefully

If you can include the following, the fix takes hours instead of days:

  • iPhone model and iOS version
  • App version (visible at the bottom of the in-app Help sheet)
  • What you were doing when it happened — the slider speed, whether the heatmap or grid overlay was on, whether onboarding had been shown
  • A screenshot, if the problem is visual

The crash-report opt-in inside iOS's standard diagnostics dialog already covers crashes silently; we receive an anonymous symbolicated stack trace from Apple if you have it enabled. For anything that is not a crash, the inbox is the right place.
